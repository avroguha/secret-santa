# Fonts

Served from the app itself, so nothing is fetched from a font CDN at runtime (works on a
closed network, and no third party sees the visitors).

| file | font | licence |
|---|---|---|

| `nunito-variable.woff2`, `nunito-italic-variable.woff2` | Nunito (The Nunito Project Authors), variable weight, Latin subset | SIL Open Font License 1.1 - `LICENSE-nunito.txt` |

Taken from the Fontsource packages `@fontsource/mountains-of-christmas@5.3.0` and
`@fontsource-variable/nunito@5.3.0` (published 2026-07-19).
